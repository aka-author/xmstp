# Требования к техническому тексту на русском языке. Грамматические конструкции

## Деепричастие и деепричастный оборот

| ID          | Требование                                                                                        |
|-------------|---------------------------------------------------------------------------------------------------|
| R.RUGR.0000 | Полный запрет: текст должен быть написан без использования деепричастий и деепричастных оборотов. |


## Возвратная форма глагола

| ID          | Требование                                                               |
|-------------|--------------------------------------------------------------------------|
| R.RUGR.0100 | При использовании глагола в возвратной форме должен быть указан деятель. |

| ID          | Пример                                                         |
|-------------|----------------------------------------------------------------|
| R.RUGR.0110 | Правка двусмысленного предложения с возвратной формой глагола. |

Следующее предложение создает двусмысленность:

*Утвержденный документ сохраняется в базе данных.*

Читатель придет в недоумение: следует ли ему после утверждения документа сохранить его в базе данных, или сохранение будет выполнено системой автоматически. Необходимо переписать это предложение одним из следующих способов в зависимости от его истинного смысла:

- *Утвержденный документ сохраняется в базе данных системой автоматически.*
- *Утвержденный документ сохраняется в базе данных пользователем.* 


## Соединение глаголов союзом *и*

| ID          | Требование                                                                                                       |
|-------------|------------------------------------------------------------------------------------------------------------------|
| R.RUGR.0120 | При соединении двух глаголов союзом *и* должна быть явно указана связь между действиями, которые они обозначают. |

| ID          | Пример                                                                |
|-------------|-----------------------------------------------------------------------|
| R.RUGR.0130 | Правка двусмысленного предложения с союзом *и* между двумя глаголами. |

Следующее предложение создает двусмысленность:

*Нажмите на кнопку Применить и сохраните сделанные изменения.*

Читателю будет неясно, сколько действий ему предписано совершить, одно или два. Необходимо переписать это предложение одним из следующих способов в зависимости от его истинного смысла:

- *Сохраните сделанные изменения. Для этого нажмите на кнопку Применить.*
- *Нажмите на кнопку Применить. Затем сохраните сделанные изменения.*


## Модальные конструкции

### Конструкции со словом *нельзя*

| ID          | Требование                                                                                                        |
|-------------|-------------------------------------------------------------------------------------------------------------------|
| R.RUGR.0130 | Конструкция со словом *нельзя* должна быть заменена на явно выражающую недоступность, запрет или нежелательность. |

| ID          | Пример                                                |
|-------------|-------------------------------------------------------|
| E.RUGR.0140 | Правка двусмысленного предложения со словом *нельзя*. |

Следующее предложение создает двусмысленность: 

*Удалять документы, по которым сформированы проводки, нельзя.*

Читатель будет недоумевать, идет ли речь об отсутствии технической возможности, административном запрете или нежелательности такого действия. Необходимо переписать это предложение одним из следующих способов в зависимости от его истинного смысла:

- *Удалить документ, по которому сформированы проводки, невозможно.*
- *Удалять документы, по которым сформированы проводки, запрещено регламентом.*
- *Удалять документы, по которым сформированы проводки, не рекомендуется.*


### Конструкции со словом *можно*

| ID          | Требование                                                                                                          |
|-------------|---------------------------------------------------------------------------------------------------------------------|
| R.RUGR.0150 | Конструкция со словом *можно* (*может*) должна быть заменена на явно выражающую доступность, допустимость или риск. |

| ID          | Пример                                               |
|-------------|------------------------------------------------------|
| E.RUGR.0160 | Правка двусмысленного предложения со словом *может*. |

Следующее предложение создает двусмысленность:

*ИИ-агент может передавать файлы пользователя на сервер.*

Читатель будет недоумевать, идет ли речь о технической возможности, юридической допустимости или риске. Необходимо переписать это предложение одним из следующих способов в зависимости от его истинного смысла.

- Указание на техническую возможность: *У ИИ-агента есть возможность передавать файлы с компьютера пользователя на сервер в Интернете*.
- Согласие пользователя с определенным положением вещей: *Пользователь предоставляет ИИ-агенту право передавать файлы с компьютера пользователя на сервер в Интернете*.
- Предупреждение о существующем риске: *Существует риск передачи ИИ-агентам файлов с компьютера пользователя на сервер в Интернете*.
