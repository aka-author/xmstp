# Using Words


## Regular Words

*Abort:* Terminate or cancel some action or process.

| Domain | Target Audience | Meaning    |
|--------|-----------------|------------|
| All    | All             | Deprecated |

*Application:*

| Domain             | Target Audience | Meaning |
|--------------------|-----------------|---------|
| Personal computers | Users           | Deprecated |
| Mobile devices     | Users           | An executable that can run on a mobile device |
| Corporate IT       | Architects, business, developers | A system delivering features to business |


*Launch:* Make a process or a program to happen. 

| Domain             | Target Audience | Meaning |
|--------------------|-----------------|---------|
| Personal computers | Users           | Deprecated |
| Mobile devices     | Users           | A program |
| Corporate IT       | Architects, business, developers | A system delivering features to business |
